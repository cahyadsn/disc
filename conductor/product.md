# Product Definition: DISC Personality Test

## Description
DISC Personality Test in PHP language based on DISC Classic.

## Problem Statement
Organizations and recruiters need a lightweight, self-hosted way to administer and interpret DISC behavioral assessments without expensive subscriptions.

## Target Users
Developers building recruitment portals or integrating psychometric tests into HR systems, as well as organizations and recruiters requiring a self-hosted behavioral evaluation platform.

## Key Goals
- **Easy Embeddability**: Enable seamless integration into external HR/recruitment platforms with zero external runtime dependencies.
- **Multilingual Support**: Support internationalization (e.g., English, Spanish, and easily expandable).
- **Accurate Scoring & Robustness**: Provide high test coverage, deterministic scoring according to DISC Classic matrices, and consistent results across diverse hosting environments.
- **Portability**: Ensure smooth operation across standard LAMP/LEMP stacks and latest PHP version support (PHP 8.3+).
