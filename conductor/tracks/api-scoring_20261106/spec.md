# Specification: REST API Scoring Endpoint

**Track ID:** api-scoring_20261106
**Type:** Feature
**Created:** 2026-11-06
**Status:** Draft

## Summary
Add a JSON REST API endpoint (`api/score.php`) that accepts candidate assessment answers (MOST and LEAST selections for the 24 DISC question groups) and returns structured DISC scores, line graph plotting points, and personality profile descriptions.

## Context
From `conductor/product.md`: The project aims to provide an accessible, self-hosted, lightweight DISC personality assessment platform with easy embeddability into external HR/recruitment systems and zero external runtime dependencies. This API endpoint allows third-party services, mobile applications, and internal recruitment tools to submit answers and receive structured psychometric profiles programmatically without rendering web HTML pages.

## User Story
As a developer integrating with HR software, I want an API endpoint to submit candidate answers and receive JSON DISC scores so that I can embed the assessment into our hiring pipeline.

## Acceptance Criteria
- [ ] Endpoint `POST /api/score.php` responds with `Content-Type: application/json`.
- [ ] Rejects non-POST HTTP methods with HTTP 405 Method Not Allowed and error JSON.
- [ ] Validates request body containing 24 question groups with valid `most` and `least` selections; returns HTTP 400 Bad Request with descriptive error details on missing or malformed inputs.
- [ ] Calculates raw scores (D, I, S, C for MOST, LEAST, and CHANGE) using `Disc\ScoreCalculator`.
- [ ] Retrieves line graph coordinates and personality profile pattern from database / fallback repository.
- [ ] Returns HTTP 200 with structured JSON response:
  - `status`: "success"
  - `scores`: Raw scores for D, I, S, C (Most, Least, Change)
  - `graph`: Graph points for Line 1, Line 2, Line 3
  - `profile`: Matched pattern code, title, and descriptive summary
- [ ] Adheres to PHP 5.6+ compatibility (no scalar/return type hints, catch `Exception`).
- [ ] High-coverage PHPUnit test suite covering successful evaluation, validation failures, method rejection, and edge cases.

## Dependencies

- Database tables / pattern definitions for DISC profile retrieval
