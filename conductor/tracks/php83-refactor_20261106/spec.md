## Summary
Refactor the codebase to establish PHP 8.3 as the minimum requirement, adopting strict typing (`declare(strict_types=1);`), typed class constants, modern PHP 8 string/utility functions (`str_starts_with`, `str_contains`, `json_validate`), unified `Throwable` error catching, and updated development guidelines.

## Context
The DISC personality assessment was historically maintained with backwards compatibility constraints down to PHP 5.6. To modernize the codebase, improve performance, ensure strict type safety, and utilize modern language features (such as `json_validate()` and typed class constants), PHP 8.3 is established as the minimum baseline.

## Problem Description / Motivation
Legacy workarounds (such as avoiding parameter type hints, avoiding `Throwable` catches, and relying on `strpos()` or regex for prefix checks) increase runtime overhead and technical debt. Moving to PHP 8.3 allows the codebase to benefit from native strict typing, better JIT/compiler optimizations, improved exception handling, and native JSON validation.
